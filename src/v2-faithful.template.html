  • Text on orange is now always ink, never white. White on #F56E3D can’t pass at any weight — your own “Tomorrow’s kitchen run” card already did it the right way, so the rule just became consistent.
  • A separate orange for small text. #F56E3D stays the fill colour exactly as drawn; #AE4519 carries the same hue where orange has to be read.

Palette

System

  • Type scale: 17 sizes → 7. The file used 10–36px in ad-hoc steps; everything now sits on 11/12/13/15/17/22/28. The 10px labels moved to 11px.
  • One gutter. Screens mixed 22px and 26px side margins and the tab bar sat at three different offsets. All 20px, on a 4pt rhythm.
  • Radii: 12 values → 5. 12/16/20/28/pill.
  • Tap targets. The −/+ glyphs were ~10px and the “Add” chip 20px tall. All controls now clear 44×44, with the extra area invisible.
  • Tab icons redrawn as aligned SVG on a 24px grid — ⌂ ▦ ↗ were text glyphs that sat off-centre and shifted per platform. Product emoji stay: those are content.

It actually works

  • The numbers are connected. Change a quantity and the estimated restock, the request badge, the urgent count and the low-stock line all move together — GH₵ 4,860 is 600 + Σ(qty × unit price), not a label.
  • States the file didn’t have: empty search, an item stepped down to zero (with undo), sending → sent, and ordered.
  • Appearance does something. The row cycles System / Light / Dark and re-themes the app for real.
  • Motion with a job: the tab pill and filter pill travel so you can see where you came from; quantities roll in the direction they changed; the large title condenses on scroll. All of it obeys prefers-reduced-motion.
  • Keyboard and screen readers: real buttons throughout, visible focus rings, role="tablist" on the bar, and a live region for counts.
